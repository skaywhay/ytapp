# YT Deck

Современный локальный веб-интерфейс для комфортного скачивания и конвертации видео и аудио с YouTube с помощью **yt-dlp** и **FFmpeg**. Никаких консольных команд — всё управление происходит в удобном тёмном интерфейсе через браузер.

---

## ✨ Возможности

- **🎬 Инспекция форматов в реальном времени**: моментальное считывание доступных качеств видеопотока (1080p, 1440p, 4K, 60fps) и аудиодорожек с указанием кодеков и примерного веса.
- **🔀 Раздельное управление каналами**:
  - **Видео + Звук**: загрузка обоих потоков и чистая склейка через FFmpeg в контейнеры `MP4`, `MKV` или `WEBM`.
  - **Только видео**: скачивание видеоряда без аудио (например, для футажей и монтажа).
  - **Только звук**: извлечение и перекодирование аудиодорожки в форматы `MP3`, `M4A`, `OPUS` или `WAV`.
- **📁 Полноценная работа с системными папками**:
  - Кнопка **«Выбрать»** открывает нативный системный диалог проводника (Windows / macOS / Linux) поверх окна браузера.
  - Корректная поддержка путей с пробелами и кириллицей.
  - Кнопка **«Открыть»** открывает целевую папку в проводнике в один клик.
  - Запоминание последней выбранной папки в браузере.
- **⚡ Мониторинг процесса по WebSocket (Socket.IO)**:
  - Плавный светодиодный индикатор выполнения.
  - Отображение текущего прогресса в процентах, скорости скачивания и объёма переданных данных.
  - Индикация этапа склейки FFmpeg.
- **🌐 Поддержка сетевого прокси**: возможность указать `socks5://` или `http://` прокси прямо в интерфейсе (с сохранением в настройках), если провайдер ограничивает доступ к YouTube.
- **🚀 Лёгкость и автономность**: быстрый бэкенд на Python (Flask + SocketIO) и чистый нативный веб-интерфейс без лишних фреймворков и тяжёлых зависимостей.

## 🛠 Предварительные требования

Перед первым запуском убедитесь, что на компьютере установлены:

1. **Python 3.9+** (рекомендуется 3.11–3.14).
2. **FFmpeg** — необходим для склейки раздельных потоков видео/аудио и конвертации звука:
   - **Windows**: скачайте готовый архив с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) (раздел *ffmpeg-release-essentials.zip*), распакуйте и добавьте папку `bin` в системную переменную `PATH`.
   - **macOS**: `brew install ffmpeg`
   - **Linux (Ubuntu/Debian)**: `sudo apt install ffmpeg`

> Проверить доступность FFmpeg можно командой в терминале:  
> `ffmpeg -version`

## 🚀 Быстрый запуск

### Вариант 1. Запуск в 1 клик на Windows

Просто дважды нажмите на файл **`run.bat`** в папке проекта.  
Скрипт автоматически:
- Создаст изолированное виртуальное окружение `.venv` (если его ещё нет);
- Установит все необходимые библиотеки из `requirements.txt`;
- Запустит локальный сервер приложения.

### Вариант 2. Ручной запуск через терминал

```bash
# 1. Перейдите в каталог проекта
cd "e:\мои проекты\ytapp"

# 2. Создайте и активируйте виртуальное окружение
python -m venv .venv
# На Windows:
.venv\Scripts\activate
# На macOS/Linux:
source .venv/bin/activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Запустите сервер
python server.py
```

После запуска откройте в браузере:  
👉 **http://127.0.0.1:5050**

*(Если порт 5050 занят другой программой, сервер автоматически найдёт свободный порт и выведет адрес в консоль).*

## 📖 Как пользоваться

1. **Вставьте ссылку** на ролик YouTube в поле сверху и нажмите кнопку **«Считать»** (или клавишу `Enter`).
2. Появится карточка с обложкой, названием, автором и длительностью ролика, а также списки форматов.
3. **Настройте каналы выгрузки**:
   - Включите/выключите чекбоксы каналов видео и аудио в блоках `03` и `04`.
   - Выберите желаемое качество из выпадающих списков.
   - Выберите итоговый формат контейнера (`MP4`, `MKV`, `WEBM`) или аудиокодек (`MP3`, `M4A`, `OPUS`, `WAV`).
4. **Укажите папку для сохранения** в блоке `02`:
   - По умолчанию файлы сохраняются в `~/Downloads/YT-Deck`.
   - Нажмите **«Выбрать»**, чтобы открыть системный диалог проводника и указать любую другую папку на диске.
5. Нажмите **«Скачать»**:
   - Начнётся загрузка с живой индикацией скорости и процентов.
   - По завершении нажмите кнопку **«Открыть папку»**, чтобы сразу перейти к готовому файлу в проводнике.

## 🔧 Решение частых вопросов

### YouTube не открывается / видео не считывается
Если в вашей сети YouTube заблокирован или замедлен:
1. Разверните аккордеон **«Сетевой прокси / SOCKS (опционально)»** под полем ввода ссылки.
2. Введите адрес вашего локального прокси, например:  
   `socks5://127.0.0.1:1080` или `http://127.0.0.1:8080`
3. Нажмите «Считать» снова — запрос пойдёт через настроенный туннель.

### Обновление yt-dlp
Алгоритмы YouTube регулярно обновляются. Если ролики перестали считываться, обновите библиотеку:
```bash
pip install --upgrade yt-dlp
```

### Видео скачивается без звука
Убедитесь, что:
- В блоке `04 Аудиоканал` включён переключатель;
- На компьютере установлен `ffmpeg` и доступен в консоли.
