# YT Deck

**YT Deck** — современное настольное приложение (Windows Desktop App) для быстрого и комфортного скачивания и конвертации видео и аудио с YouTube с помощью **yt-dlp** и **FFmpeg**.

Приложение открывается в **собственном нативном окне** (на базе системного движка Microsoft Edge WebView2), без чёрных окон консоли и без необходимости открывать сторонние вкладки в браузере.

---

## ✨ Возможности

- **🖥️ Полноценный десктопный режим**:
  - Запуск в отдельном окне программы с аппаратным ускорением Chromium/Edge.
  - Тёмная премиальная тема (Obsidian / Zinc) без белых мерцаний при старте.
  - Оконная подсистема Windows: никаких всплывающих окон командной строки.
  - При закрытии окна приложение и все фоновые процессы завершаются чисто.
- **🎬 Инспекция форматов в реальном времени**:
  - Моментальное считывание доступных качеств видеопотока (1080p, 1440p, 4K, 60fps) и аудиодорожек с указанием кодеков и примерного веса.
- **🎙️ Выбор звуковой дорожки и дубляжей (Multi-Audio / Dubs)**:
  - Автоматическое распознавание всех мультиязычных дубляжей видео (актуально для каналов вроде MrBeast, TED, Kurzgesagt и др.).
  - Удобный выпадающий список языков с автоопределением русского дубляжа или оригинальной дорожки.
  - Возможность скачивать видео с любым выбранным дубляжом либо выгружать конкретную аудиодорожку отдельно.
- **🔀 Раздельное управление медиапотоками**:
  - **Видео + Звук**: загрузка обоих независимых потоков и чистая склейка через FFmpeg в контейнеры `MP4`, `MKV` или `WEBM`.
  - **Только видео**: скачивание видеоряда без аудио (для монтажа, футажей, b-roll).
  - **Только звук**: быстрое извлечение и перекодирование аудиодорожки в форматы `MP3`, `M4A`, `OPUS` или `WAV`.
- **📁 Нативная работа с папками и проводником**:
  - Кнопка **«Выбрать»** открывает нативный системный диалог проводника Windows поверх окна программы.
  - Полная поддержка кириллицы и пробелов в путях.
  - Кнопка **«Открыть»** открывает папку с готовым файлом в проводнике Windows в один клик.
  - Автоматическое запоминание последней выбранной директории.
- **⚡ Мониторинг процесса в реальном времени (Socket.IO)**:
  - Плавный неоновый индикатор выполнения.
  - Отображение текущего прогресса в процентах, скорости скачивания и переданного объёма данных.
  - Отдельная индикация этапа склейки потоков через FFmpeg.
- **🌐 Встроенная поддержка сетевого прокси**:
  - Возможность указать `socks5://` или `http://` прокси прямо в интерфейсе (с сохранением в настройках), если провайдер ограничивает доступ к серверам YouTube.
- **🔍 Умный поиск FFmpeg**:
  - Автоматически находит FFmpeg в системном `PATH`, а также если положить `ffmpeg.exe` в папку рядом с приложением.

## 🚀 Быстрый запуск

### Вариант 1. Запуск через готовый .EXE (Рекомендуется)

Просто дважды кликните по файлу:
👉 **`YT_Deck.exe`** (в корне проекта или в папке `dist/`).

*Приложение мгновенно запустится в собственном окне.*

---

### Вариант 2. Запуск через скрипт `run.bat`

Если вы хотите запускать проект из исходного кода:
1. Дважды нажмите на **`run.bat`** в папке проекта.
2. Скрипт сам создаст виртуальное окружение `.venv`, установит все зависимости и запустит настольное приложение.

---

### Вариант 3. Ручной запуск через терминал

```bash
# 1. Перейдите в каталог проекта

# 2. Создайте и активируйте виртуальное окружение
python -m venv .venv
.venv\Scripts\activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Запустите десктопное приложение
python server.py

# (Опционально) Запуск в режиме веб-сервера для браузера:
python server.py --browser
```

## 🛠 Сборка собственного .EXE

В проект уже включена готовая конфигурация для сборки переносимого автономного приложения:

1. Запустите скрипт **`build_exe.bat`**.
2. PyInstaller автоматически соберёт бинарный файл со всеми зависимостями, встроенными шаблонами, стилями и фирменной иконкой.
3. Готовый файл автоматически появится в корне проекта: **`YT_Deck.exe`** (и копия в каталоге `dist/`).

## 📖 Как пользоваться

1. **Вставьте ссылку** на ролик YouTube в поле ввода сверху и нажмите кнопку **«Считать»** (или клавишу `Enter`).
2. Появится карточка с превью, названием, автором и длительностью ролика, а также списки форматов.
3. **Настройте каналы выгрузки**:
   - Включите/выключите чекбоксы видео и аудио в блоках `03` и `04`.
   - Выберите желаемое разрешение (например, `1080p · MP4`) и качество аудио.
   - Выберите формат контейнера (`MP4`, `MKV`, `WEBM`) или аудиокодек (`MP3`, `M4A`, `OPUS`, `WAV`).
4. **Укажите папку для сохранения** в блоке `02`:
   - По умолчанию файлы сохраняются в `~/Downloads/YT-Deck`.
   - Нажмите **«Выбрать»**, чтобы выбрать любую папку через системный проводник.
5. Нажмите большую кнопку **«Скачать»**:
   - Следите за живым индикатором загрузки и скорости.
   - По завершении нажмите кнопку **«Открыть папку»**, чтобы перейти к файлу.

## 🔧 Решение частых вопросов

### YouTube не открывается / видео не считывается
Если в вашей сети YouTube замедлен или заблокирован:
1. Разверните блок **«Сетевой прокси / SOCKS (опционально)»** под полем ввода ссылки.
2. Введите адрес вашего локального прокси, например:  
   `socks5://127.0.0.1:1080` или `http://127.0.0.1:8080`
3. Нажмите «Считать» снова — запрос пойдёт через настроенный туннель.

### Обновление yt-dlp
Алгоритмы видеохостинга регулярно меняются. Чтобы обновить модуль выгрузки:
```bash
pip install --upgrade yt-dlp
```
*(Для пересборки .exe после обновления запустите `build_exe.bat`).*

### FFmpeg не найден
FFmpeg необходим для склейки качественного видео со звуком:
- Добавьте `ffmpeg` в системную переменную `PATH`, **ЛИБО**
- Просто положите файл `ffmpeg.exe` в ту же папку, где лежит `YT_Deck.exe`.
