# YT Deck

Локальное веб-приложение с современным интерфейсом поверх `yt-dlp`: вставляете ссылку, выбираете качество видео и звука, скачиваете вместе или по отдельности. Никакой консоли и мануалов — всё через браузер.

## Что нужно установить один раз

1. **Python 3.9+**
2. **ffmpeg** — нужен для склейки видео со звуком и конвертации аудио.
   - Windows: скачайте с https://www.gyan.dev/ffmpeg/builds/ и добавьте папку `bin` в PATH.
   - macOS: `brew install ffmpeg`
   - Linux: `sudo apt install ffmpeg`

Проверить, что ffmpeg установлен: `ffmpeg -version` в терминале.

## Установка приложения

```bash
cd yt-deck
pip install -r requirements.txt
```

## Запуск

```bash
python server.py
```

Откройте в браузере: **http://127.0.0.1:5050**

Дальше можно повторять `python server.py` каждый раз, когда нужно скачать видео — сделайте ярлык/bat-файл, если хотите запускать в один клик (пример `run.bat` для Windows и `run.sh` для macOS/Linux ниже).

## Как пользоваться

1. Вставьте ссылку на видео YouTube в поле сверху → «Считать».
2. Появится обложка, название и список доступных качеств видео и звука.
3. Включите/выключите переключателем нужный канал:
   - **оба включены** → видео и звук скачаются и склеятся в один файл (MP4/MKV/WEBM на выбор);
   - **только видео** → скачается видеодорожка без звука;
   - **только звук** → скачается и сконвертируется аудиодорожка (MP3/M4A/OPUS/WAV на выбор).
4. Нажмите «Скачать» — прогресс отображается сегментным индикатором.
5. По готовности можно открыть папку с файлом кнопкой «Открыть».

Папка загрузок по умолчанию: `~/Downloads/YT-Deck` (можно поменять прямо в поле «Папка сохранения» перед нажатием «Скачать»).

## Если YouTube доступен только через VPN

Иногда браузер работает через VPN, а сам сервер (Python-процесс) — нет, из-за split tunneling в настройках VPN-клиента или особенностей сети. Если после запуска сервера видите ошибку вида `getaddrinfo failed` или `Unable to download API page`:

1. Проверьте в настройках вашего VPN-клиента, не исключён ли терминал/Python из туннеля (split tunneling / app exclusions).
2. Как запасной вариант — в приложении есть поле «Прокси (опционально)» под строкой ссылки. Укажите там адрес SOCKS5 или HTTP-прокси (многие VPN-клиенты поднимают локальный прокси, например `socks5://127.0.0.1:1080`) — тогда yt-dlp будет ходить в сеть через него напрямую, независимо от системных настроек.

## Обновление yt-dlp

YouTube периодически меняет свою внутреннюю кухню, из-за чего старые версии `yt-dlp` могут переставать работать. Если приложение вдруг перестало получать данные о видео, обновите библиотеку:

```bash
pip install --upgrade yt-dlp
```
